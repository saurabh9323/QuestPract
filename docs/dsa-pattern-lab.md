# DSA Pattern Lab

Route `/dsa-patterns/`, under Learn. Twenty core families: Map, Set, two pointers, sliding window, stack, BFS, binary search, prefix sums, DFS, backtracking, DP, greedy, heaps, monotonic stack, intervals, fast/slow pointers, union-find, topological order, trie and bit manipulation. Not an exhaustive catalogue of every algorithm.

Lessons provide signals, counterexamples, baseline/optimization reasoning, invariant, analogy, scenarios, decision flow, replay and account-synced notes. No complete solution code is shown. Existing eight pattern guides supply authored cell replays; twelve additional families use authored state storyboards. Both are explicit simulations, not runtime/compiler/backend traces. Slot labels do not represent JavaScript memory addresses. Playback starts only on request; reduced-motion disables cell transitions. HTML export is offline, interactive, escaped, and does not include account notes.

Validation: TypeScript and focused content/export tests. Browser interaction/layout and live account synchronization not verified. No push performed.
